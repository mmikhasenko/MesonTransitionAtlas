Meson transition atlas

Every decay that GIModel.jl can evaluate, drawn on the model's own spectrum for ten flavor sectors of the Godfrey–Isgur relativized quark model. Masses and widths are model predictions with the paper's parameters; no experimental input. All widths are in MeV.

Hover or tap a level to isolate its transitions and list all of them on the right; tap empty space to reset. Each level shows at most four exits (decays leaving the diagram); the panel and the table list all. † marks a width computed in the S+P basis, without D-wave mixing.

Operators and conventions

  • Strong: elementary emission of π, K, η, η′ (PseudoscalarEmission). Couplings from the strong-decay tutorial: h/g from the paper's S₀/A fit, g fixed by Γ(ρ → ππ) = 149.1 MeV (). Charge channels are summed; for two pseudoscalar daughters one rearrangement is kept, with the lighter of π < K < η < η′ as the emitted meson; identical daughters get ½. Decays needing pair creation (³P₀), such as ψ(3770) → DD̄ or ρ → K K̄* with an s s̄ pair, are not in the operator.
  • Radiative (PhotonEmission): E1 (S ↔ P), M1 (S ↔ S, direct and hindered), M2 (³P₂ → ¹S₀). Computed for each charge state; switch with the "Charge state" control.
  • Gluonic (GluonicAnnihilation, αs(M)): only for c c̄ and b b̄; for light quarks the perturbative rate has no meaning.
  • γγ and e⁺e⁻ for neutral hidden-flavor states; ℓν for the charged ground-state pseudoscalars with PDG CKM elements.

Read before quoting

  • Computed with GIModel.jl v0.4.2 at commit cc7bf22, which carries the corrected singlet E1 factor (¹P₁ → ¹S₀ takes 1/3, as ³PJ → ³S₁).
  • Quarkonium-to-quarkonium hadronic transitions (ψ(2S) → J/ψ η, J/ψ ππ) vanish in the emission operator: a c quark cannot emit an η made of light quarks. They need the QCD multipole expansion, which is not implemented.
  • Zero widths: ³P₁ → ¹S₀ (spin-flip E1) and ³P₂ → ¹S₀ (M2) vanish for equal quark masses, C-forbidden. Shown dashed with the "zero-width" chip.
  • Kinematics use model masses throughout (the model pion is 149 MeV). Widths are not separately convergence-checked; the oscillator solver certifies energies only.
  • Partial widths of a level do not add up to its total width: channels outside the operators above are missing.

    Reproduce

    The repository pins the exact package version in Project.toml and Manifest.toml. With Julia 1.11:

    git clone https://github.com/mmikhasenko/MesonTransitionAtlas.git
cd MesonTransitionAtlas
sh run.sh 3          # about 45 minutes; writes data/transitions.json and site/data.js

    The page itself needs only site/index.html and site/data.js; open the HTML file directly, no server required.
